# File Counter

A Node.js utility that reads a text file and displays the file name, word count, line count, and character count.

## How to Run

### 1. Basic Usage

Provide a file path as an argument:

```bash
node fileCounter.js path/to/file.txt
```

### 2. Example

```bash
node fileCounter.js "d:\NodeJs projects\fileCounter\info.txt"
```

## Output

The script will display:

- **File:** The name of the file
- **Word Count:** Total number of words
- **Line Count:** Total number of lines
- **Character Count:** Total number of characters

## Error Handling

If the specified file path is missing or the file cannot be read, an error message will be displayed.
